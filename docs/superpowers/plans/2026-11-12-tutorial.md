# In-game Tutorial Implementation Plan

> **For agentic workers:** Use the native implementation workflow with independent integration verification and review. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Teach cane sight, danger, throwing and crouching during the opening encounter.

**Architecture:** TutorialDirector owns the sequence, temporary camera guidance and allowed actions. PlayerController obeys those actions, GameSession owns lifecycle/UI, and ListenerCreature exposes narrow opening-cue hooks while retaining normal AI.

**Tech Stack:** Unity 2023.1.14f1, C#, built-in rendering, IMGUI, existing NavMesh and Rigidbody systems.

**Spec:** ../specs/2026-11-12-tutorial-design.md

## Global constraints

- Replay on each new run and after death; never persist completion to PlayerPrefs.
- Keep existing hearing, five-second committed distraction, browser controls and outline rendering.
- Freeze world during pickup/throw; only the requested action advances each gate.
- Skip remains available on title/pause and through a keyboard shortcut during play.

## Review focus

- Walking backward or sideways still yields a visible, reachable pickup.
- Pausing a frozen step does not unfreeze the creature on resume.
- Repeated or held keys cannot bypass camera transitions or throw a missing object.
- Skip at any phase restores time, input, hearing and temporary outlines.
- Real prop collision produces a reachable distraction, then full inspection and return.
